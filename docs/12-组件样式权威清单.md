# 12 · 组件样式权威清单（UI 一致性基线）

> 2026-11-24：整理前端组件样式时建立。**本文是"改样式前必看"的基线**。
>
> **背景**：全站基础组件类（`.btn` / `.card` / `.modal` / `.form-input` 等）被**重复定义在多个 CSS 文件**里，
> 靠层叠顺序（后加载覆盖先加载）决定最终效果。经扫描统计：
>
> | 选择器 | 定义次数 | 分布 |
> |---|---|---|
> | `.card` | 9 | 03-layout / 04-components / animations / ui-components×3 / ui-enhance / 99-design-system |
> | `.btn` | 8 | 04-components / 99-design-system×3 / animations / ui-components×3 |
> | `.modal` | 6 | 04-components / 99-design-system / ui-components×3 / ui-enhance |
> | `.btn-sm` `.btn-outline` `.badge` | 各 5 | 分散 |
> | `.form-input` `.btn-accent` | 各 2 | 分散 |
>
> 冗余定义合计 **38 处**。
>
> **好消息**：实测最终渲染结果**是一致的**（层叠结果稳定），所以这是**可维护性问题，不是视觉 bug**。
> **风险提示**：因为效果依赖加载顺序，**改动任一处都可能改变最终视觉**。改前务必对照本文并实测。

## 0. 结论先行：权威定义在哪

**`99-design-system.css` 就是按钮/控件的"单一事实来源"**——它在该文件 33 行处的注释里已明确写明：

> 「覆盖此前 3 个文件 7 处互相冲突的 `.btn` 定义，统一为单一事实来源」

因为它是**最后加载**的基础样式文件，所以前面的 `.btn` 定义（`04-components.css`、`ui-components.css` 里）**全部被层叠覆盖，属历史遗留死代码**。

因此：
- **改按钮样式 → 只改 `99-design-system.css`**，其他文件里的 `.btn` 不要动（也不要以为它们生效了）。
- 同理 `.card` 以 `ui-components.css` 最后一段 + `ui-enhance.css` 为准，`.form-input` 以 `baidu-modern.css`（最后加载）为准。
- 后续重构的**最大收益就是删掉这些死代码**（见 §6 批次 1），而不是重新设计。

## 1. CSS 加载顺序（决定层叠优先级）

`index.html` 中的实际顺序（后加载优先级更高）：

```
1.  style.css
2.  ui-components.css        ← 含 .btn 增强 / .btn-accent / .btn-outline
3.  ui-enhance.css           ← 含 .card 覆盖、移动端字号兜底
4.  99-design-system.css     ← 含 .btn 权威定义（padding/min-height/font-size）
5.  nav-scroller.css
6.  home-featured.css
7.  home-enhance.css
8.  animations.css           ← 含 .btn:hover 动效
9.  likes-anim.css
10. feature-disabled.css
11–15. 06b-presence / 06-members / collections / 10-social / baidu-modern
       （以上 5 个 + worlds-panel 用 media="print" 异步加载，noscript 兜底）
16. worlds-panel.css
```

> `media="print"` 异步加载是**有意的性能优化**（P2-21，避免非首屏 CSS 阻塞 LCP），
> 加载后由浏览器空闲时补全，**不是重复引入 bug**。

## 5. 改动规范（重要）

1. **改任何基础组件前**，先用本文对照最终值，改完必须实测（暗色/亮色、桌面/移动端各看一次）。
2. **不要新增第 9 处 `.btn` 定义**——需要变体请加到 `99-design-system.css` 的按钮区块，并在本文登记。
3. **不要相信单一文件里的声明值**——它可能被后面的文件覆盖。以实测 computed style 为准。
4. 新增组件请优先复用 `--radius-*` / `--space-*` / `--ctl-h-*` token，不要写魔法数字。
