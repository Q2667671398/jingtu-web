## 5. 调研来源与方案要点
- **Activity Heatmap**：GitHub 风格贡献图是成熟模式；实现要点=按 `WEEKDAY(ts)`+`HOUR(ts)` 聚合到 7×24 矩阵，前端 CSS Grid 渲染、色阶映射、峰值统计；注意键盘可访问性（button + aria-label）与空单元格 aria-hidden。[GitHub 风格热力图实现 PR](https://github.com/certlab/certlab/pull/452) · [VRCX Charts/Analytics 设计](https://deepwiki.com/vrcx-team/VRCX/5.8-charts-and-analytics)
- **命令面板/模糊快搜**：连续命中与词首命中加权、长文本轻微惩罚、匹配失败返回 -1 过滤；键盘导航保持焦点在输入框、用 activeIndex 高亮（不真移焦点）。[纯前端命令面板模糊匹配](https://bbs.huaweicloud.com/blogs/506169) · [框架无关命令面板引擎](https://www.npmjs.com/package/@crimson_dev/command)
- **可定制仪表盘**：拖拽式 widget + 碰撞检测 + 响应式断点 + 主题系统，vanilla JS 可用（iaz-dashboard 等）。[iaz-dashboard](https://www.npmjs.com/package/iaz-dashboard/v/1.4.1)
- **媒体库图片分档**：列表缩略图/详情大图分离，配合 srcset 让浏览器按设备选尺寸，避免"小卡片下载原图"流量浪费；无限滚动用 IntersectionObserver 渐进加载。[相册图片三档+srcset](https://www.cnblogs.com/dogma/p/23459562) · [无限滚动机制](https://github.com/feder-cr/invisible_playwright/blob/main/docs/how-to-scrape-image-galleries-playwright.md)
- **pronouns 等自由文本字段**：应为自由字符串、不假设固定枚举（如 she/her、they/them、ask me）。[eduPersonDisplayPronouns](https://wiki.refeds.org/display/STAN/eduPersonDisplayPronouns)
